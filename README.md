# Exercícios de Raciocínio Algorítmico

Este repositório contém todas as listas de exercícios desenvolvidas na disciplina de Raciocínio Algorítmico.

## Objetivo

O objetivo deste repositório é armazenar os exercícios realizados durante a disciplina para acompanhamento da realização das atividades propostas.

## Conteúdo

As listas incluem exercícios relacionados a:

- Listas e vetores;
- Estruturas condicionais;
- Matrizes;
- Dicionários;
- Funções;
- Imports;
- Modularização;

## Tecnologias utilizadas

- Linguagem Python
- PyCharm
- Git
- GitHub
